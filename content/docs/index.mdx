YellowBird is a video transcoding service. You upload a file through the API or the web workspace, and the system produces a JPEG thumbnail, a 10-second preview clip, and H.264 streams at 360p, 720p, and 1080p. Encoding runs in a dedicated worker process separate from the HTTP server, so a heavy 4K encode never touches the API's response latency.

The project lives across three repositories with distinct responsibilities. The Go module handles everything server-side — receiving uploads, writing records to PostgreSQL, routing job IDs through Redis, and running FFmpeg in a separate binary. The Next.js workspace is the browser interface users authenticate against. The Terraform repository defines the AWS infrastructure running it all in production.
