title: Workspace
description: The YellowBird workspace. A Next.js app for sign-in, upload, job status, and renditions.
---

The workspace is the Next.js app hosted at `yellowbird.amaanworks.me`. It is not this docs site. The API origin is `NEXT_PUBLIC_API_URL`, and the client falls back to `https://api.amaanworks.me`. Every call is under `/api/v1`.

| Route | What you do there |
| --- | --- |
| `/login`, `/register` | Create a session. Login stores the JWT from `POST /users/login`. |
| `/` | Pick or create a project, drop a file, watch upload progress, then switch among renditions as they appear. |
| `/library` | Previously uploaded media. Open one in the workspace, or delete a rendition. |

Upload is `POST /media` with `FormData`: `project_id` and `file`. The browser uses `XMLHttpRequest` so it can report `xhr.upload.onprogress`. After the API returns the media id, the page polls media, jobs, and renditions together. Polling stops at 15 minutes, when the media status is `ready` or `failed`, or when no job is still `queued` or `running`.

The player on the home page is the local file while the upload is in flight, then the rendition URL the API stored. Labels are the rendition type or the target height (`360p`, `720p`, `1080p`). Poster and preview keep those names.

Sign-out clears the token the client stored. Protected calls send `Authorization: Bearer <token>`. A 401 from a protected call drops the session.

Request paths and bodies are on [API](./api).
